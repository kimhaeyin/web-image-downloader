产品介绍

它解决的是「一张张右键另存为」的麻烦

电商商品页的图片往往分散在主图区、详情长图区、SKU 图和 CSS 背景图里， 还有大量懒加载和尺寸后缀。手工保存既慢又容易漏。 图提取 ImageGrab 在页面右下角提供一个按钮，点一下就完成采集、去重与过滤， 并在独立页面里集中展示。

适合什么场景

  • 整理竞品商品图，做选品对比
  • 为自己的商品页准备图片素材
  • 需要把一批商品图统一转成 PNG
  • 逐个 SKU 检查主图是否齐全

它是怎么工作的

  1. 内容脚本读取你正在浏览的页面 DOM，收集图片地址
  2. 归一化后去重，并过滤图标、占位图、埋点像素与过小图片
  3. 在扩展内置的展示页里网格预览，显示尺寸与地址
  4. 勾选后取回图片字节，用 canvas 转成 PNG 交给浏览器下载

关于边界，说明清楚

插件只读取你当前已经打开的页面上可见的图片地址， 不绕过登录、不绕过访问控制、不伪造 Referer 或 Cookie 去规避防盗链。 如果某个图片服务器的防盗链策略拒绝了扩展发起的请求， 插件会明确告诉你这一张转换失败，而不会把原格式文件改名成 .png 冒充成功。

核心功能

从采集到落盘的六个环节

01

图片提取

兼容 img 的 src、currentSrc、srcset， 以及 data-src、data-lazy-src、data-original、 data-ks-lazyload 等常见懒加载来源，并处理 CSS background-image。

02

智能过滤

按归一化地址去重，过滤图标、logo、占位图、统计埋点像素与 1×1 图片， 并把宽和高都小于阈值的图片剔除。阈值可以在插件弹窗里调整。

03

集中预览

在新标签页用网格展示全部结果，每张卡片显示宽高尺寸与完整图片地址， 附带复制链接、单独下载、在新标签页打开原图三个快捷操作。

04

自由勾选

支持全选、取消选择、反选，也可以点击缩略图逐张切换； 已选数量实时显示在下载按钮上，避免下载多余的图片。

05

PNG 转换

取回图片字节后用 canvas 重新编码为 PNG。 转换失败时会说明具体原因，并可以按原格式下载，绝不会伪造转换成功的结果。

06

批量下载

串行调用浏览器下载接口，文件名按 商品图_001.png 递增编号， 过程显示处理进度，结束后给出成功、原格式回退与失败的数量明细。

使用提示

  • 连续下载多张时，Chrome 可能询问「是否允许下载多个文件」，需要点允许。
  • 如果某张图只有缩略图，可以打开插件弹窗里的「尝试改写为原图直链」开关再重新采集。
  • 详情长图通常需要先滚动到底部，或切换目标 SKU，再点一次「重新采集」。
  • JPEG 转 PNG 会让文件变大数倍，介意体积可以在展示页关闭「转换为 PNG」。

安装步骤

五步装好，不需要应用商店

插件以「已解压的扩展程序」方式加载，全程不需要登录任何账号。

  1. 1

    下载 ZIP 安装包

    点击页面下方的「下载插件 ZIP」，保存 imagegrab.zip 到本地。

  2. 2

    解压到一个固定目录

    解压后会看到一个直接包含 manifest.json 的文件夹。 加载之后请不要删除或移动这个文件夹，Chrome 每次启动都会读它。

  3. 3

    打开扩展管理页面

    在地址栏输入 chrome://extensions 并回车。 这个地址只能手动输入，不能通过链接跳转。

  4. 4

    打开右上角的「开发者模式」

    打开后页面顶部会出现「加载已解压的扩展程序」等按钮。

  5. 5

    加载已解压的扩展程序

    点击该按钮，选中第 2 步解压出来的文件夹。 装好后打开任意支持的商品页面，右下角就会出现「获取图片」按钮。
